## Project Description

This project involved diagnosing and repairing DNS and DHCP services in Ubuntu using KillerCoda.

The company network is `192.168.19.0/24`, and its internal DNS server is `192.168.19.10`.

## Faults Repaired

1. Incorrect BIND forward zone file path.
2. Incorrect API DNS A record.
3. Incorrect DNS resolver advertised by DHCP.
4. Firewall blocking incoming UDP DNS traffic.
